本游戏地图原型基于PLopSaga
所以地图位于BackToDawn\Assets\PlopSaga_v3.0\Scenes下
开始页面为Gamestart
经由分支选择路径改变，在最后的Demo_10跳转到结尾CG并退出游戏，其中路径可能由于模型性能大小出现不适配可以通过显式更改主角代码实现

核心角色组件位于BackToDawn\Assets\Pixel Heroes Pack目录下，作为玩家的行为代码在BackToDawn\Assets\Pixel Heroes Pack\Demo\Scripts目录下

敌对代码以及其他额外功能代码（场景切换，血条，重生，陷阱之类）位于Assets\Scripts目录下

Shop游戏商店
